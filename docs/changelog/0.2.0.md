# 0.2.0 — Multi-architecture platform

**Released:** 2026-06-11 (PR #34, "0.2.0 platform merge") &nbsp;·&nbsp;
**Targets:** STM32F401RE (Cortex-M4) + ATmega328P (AVR)

The release that turned NavHAL from a single-target STM32F4 HAL into a **modular,
multi-architecture platform**, and cut it to the `stable` branch under a
SemVer-gated process. Consolidates milestones **M4–M8**.

## What's new

### Modular, Kconfig-driven build (M4, M7 §7.2)
- **`ARCH` / `VENDOR` / `FAMILY` / `BOARD` axes** resolved from Kconfig.
- Per-arch CMake fragments and per-port Kconfig fragments — adding a target is a
  fragment, not edits to a central ladder.
- Per-driver **capability sub-options** (e.g. the DMA backends), with sources and
  include paths selected from the resolved `.config`.

### Standardized v1 API + conformance (M5, M8)
- The **`hal_*` v1 API** standardization: uniform `hal_status_t` return
  contract, `hal_features.h` capability macros, per-driver audit; samples and
  internal code migrated off the pre-standardization API (kept as back-compat
  aliases — no removals).
- **`HAL_API_VERSION` frozen at 1.**
- A **HAL contract conformance suite** (portable, runs on every port) plus a test
  reorganisation into **portable / capability / arch** tiers.
- CI that builds only the arches affected by a PR.

### Second architecture: ATmega328P / AVR (M6)
- A real AVR target: Kconfig + arch-conditional build, the AVR arch interrupt
  backend, and the ATmega328P header/board layer.
- AVR vendor drivers: **UART** (double-speed baud), **general-purpose timer**,
  **PWM**, **I²C (TWI)**, **SPI**, **CRC** (software), **flash**.
- Samples reorganised **by capability into three tiers** so the portable tier
  runs on both Cortex-M4 and AVR; `avrdude` flashing; `flash.sh` made
  target-aware.

### Process
- First **SemVer-gated** stable release: every merge into `stable` requires a
  version bump.

## Patch releases
- **0.2.1 – 0.2.6** — bug fixes and small follow-ups on the stable line
  (e.g. `hal_i2c_deinit` restore, UART/VFS fixes), no API changes.
